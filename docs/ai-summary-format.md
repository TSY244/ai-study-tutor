# AI 学习总结格式（study-summary/v1）

适用于新生成的视频图文总结、教师教纲、学生笔记，以及手动重新生成的学习总结。历史文档保留原样；测验、批阅和总结评估继续使用各自的结构化结果契约。

```markdown
# 学习主题名称

## 综合总结

### 内容概览
主题、适用场景与学习目标。

### 核心知识点
关键概念、公式、方法、适用条件。

### 知识结构
知识之间的联系与建议学习顺序。

### 示例与应用
资料中的例子、演示步骤与应用。

### 结论与复习
关键结论及复习自测问题。

### 来源与局限
原始来源、已有时间戳或章节、采样范围、缺失和不确定信息。
```

标题不超过 80 字符，应概括学习主题。不得编造资料中不存在的事实、例子、来源或时间戳；缺失内容明确注明。教纲在以上结构中体现教学目标、讲解顺序与课堂活动；笔记强调理解、记忆与复习。视频完整字幕与画面记录独立保留，不以总结替代原文。

提示和发布校验共同使用 `backend/internal/ai/summary_format.go`。章节顺序或内容不合格时按结构校验失败重试，不发布不完整结果。

创建课程时名称可省略、为空或仅有空白，先显示“待 AI 命名”。首次成功发布教纲（或单独重生成笔记）时，以 AI 总结的主题标题命名。无内容或 AI 失败时继续等待；手动名称及已经生成的名称不被后续任务覆盖，发布与命名同一事务提交。已有课程不会自动改名。
