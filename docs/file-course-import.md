# 图片、扫描 PDF、PPTX 与批量导入

## 入口

- **新建课程**：选择“图片 / 扫描 PDF”“PPTX 课件”或“批量文件”。标题可留空，由 AI 根据内容命名。
- **已有课程**：课时列表上方点击“批量导入”。新课时追加到现有最大课时序号后；一个文件建立一个课时。
- **已有空白课时**：通过“导入素材 → 文件”上传单个文件，同样支持图片、扫描 PDF 和 PPTX。

每批最多 50 个文件，按选择顺序依次上传。普通文件最大 100 MiB，音频最大 2 GiB，最终仍受服务端 `MAX_UPLOAD_BYTES` 限制。PDF/PPTX 最多 300 页；PPTX 展开后最多 512 MiB、单个成员最多 32 MiB、最多 1,000 张待识别图片。

支持 PNG、JPEG、WebP、TIFF、BMP、GIF、PDF、PPTX、DOCX、TXT/Markdown、SRT/VTT、HTML，以及已有音视频格式。旧版 `.ppt` 需另存为 `.pptx` 或 PDF。

## 提取与生成

1. 图片通过 Worker 内置的 [Tesseract OCR](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html) 识别简体中文、繁体中文和英语。WebP 先转换为 PNG。
2. PDF 优先使用 Poppler 提取原生文字，保留页码。每页不足 20 个文字/数字字符时渲染该页并进行 OCR，因此扫描 PDF 及原生页、扫描页混合的 PDF 都可以导入。空白页不生成内容。
3. PPTX 按 PresentationML 中的幻灯片顺序读取文字、表格段落、演讲者备注、图表缓存文字及数据，对内嵌常见位图进行 OCR。输出保留幻灯片编号。外部资源链接不会被抓取。
4. 所有结果进入同一原文规范化、分块、AI 总结管线，保留原文并生成学生笔记、教师教纲，供知识点和测验能力继续使用。原文与生成文档沿用任务完成时统一发布的事务语义。

OCR 与语音转写在本机运行；AI 总结使用当前模型网关。OCR 可能误认手写、公式、低清图片和复杂排版，重要术语或数字建议核对原文。

PPTX 当前提取可读取的内容，未按整张幻灯片运行视觉模型；纯图形关系、动画、SmartArt、EMF/WMF 等特殊矢量图不保证完整识别，可导出为 PDF 后导入。PDF 内含大量原生文字的页面直接使用原生文字，不额外解释同页插图。

## 批量进度与重试

- 每个文件有独立课时、上传幂等键和后台任务。界面区分“上传中”“已入队”和“导入失败”。已入队表示后台仍可能正在提取或生成，并非总结已经完成。
- 某个文件创建或上传失败时继续处理其余文件。“重试未完成项”仅提交尚未成功入队的文件，复用已创建的课程、课时和相同上传意图。
- 同一页面中的网络重试保留未明确完成的创建请求及课时序号，避免请求已提交但响应丢失时重复创建。
- 上传时保持页面打开。上传成功后可进入课时或任务中心查看后台进度；AI 生成失败可在对应课时/任务中重试。批量选择和上传重试状态保留在当前表单中，刷新页面不会恢复本地文件选择。

## 部署与验证

Worker 镜像增加 Tesseract 及 `chi_sim`、`chi_tra`、`eng` 语言包，复用已有 Poppler、FFmpeg。无需新增 OCR API Key，也无需数据库迁移。使用更新后的 Worker、API 与前端镜像。

代码测试覆盖混合 PDF 的逐页识别、空白页、工具缺失、取消、PPTX 实际页序/备注/图表/图片文字、格式签名校验、批量部分失败与幂等重试、已有课程分页后的序号分配，以及音频回归。
