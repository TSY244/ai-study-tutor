# 音频创建课程

## 使用

- 新建课程页选择“音频导入”，选择文件和音频语言，再点击“创建并导入音频”。课程标题可留空，AI 根据内容命名。
- 已有课程中新建课时，在“导入素材 → 音频”上传。普通“文件”入口选择音频时，默认也会启用本地转写。
- 支持 MP3、WAV、M4A、FLAC、OGG、OPUS、AAC。音频最大 2 GiB，仍受服务端 `MAX_UPLOAD_BYTES` 的最终限制；超过限制时压缩或分段上传。
- 上传进度与后台转写/AI 生成进度分开展示。上传失败重试会复用已创建的课程、课时及同一上传意图，不重复创建。

## 数据流程

1. 校验文件签名，保存上传素材并创建导入任务。
2. 优先读取内嵌字幕；没有字幕时将音轨转换为 16 kHz 单声道 PCM，再运行本地 Whisper。语言默认自动识别，也可选择中文、英语等。
3. 规范化完整转写文本、分块，随后将文本交给现有 AI Provider。
4. 使用统一 AI 总结格式生成学生笔记与教师教纲；保留转写原文，供后续知识点分析和测验使用。文档沿用现有任务完成时统一发布的事务语义。

转写不依赖模型网关；AI 总结仍使用当前网关配置。自动语音识别可能出现同音词、专有名词和数字错误，可以查看原文后修订。

## 部署

Worker 镜像内置 [whisper.cpp v1.9.5](https://github.com/ggml-org/whisper.cpp/releases/tag/v1.9.5) 和 [多语言 base 模型](https://huggingface.co/ggerganov/whisper.cpp)。源码固定到提交 `d1be6fde11ac6e0407606b4e42fe72d34add8037`，模型固定到版本 `5359861c739e955e79d9a303bcbc70fb988958b1`，构建时校验 SHA-256。模型路径默认 `/opt/whisper/models/ggml-base.bin`。

当前部署与示例已将 `WORKER_JOB_TIMEOUT` 调整为 `4h`，给长录音转写和 AI 生成留出时间；其他部署可按机器速度与录音时长调整此参数。

已有自定义 `WHISPER_MODEL_PATH` 配置会保留；使用自定义模型时，需在容器中提供兼容模型文件。首次构建下载模型，运行时音频识别在本机完成。

## 其他创建方式

| 方式 | 当前基础或后续开发范围 |
| --- | --- |
| 粘贴文本、TXT/Markdown、字幕、PDF、DOCX、HTML | 已有文本提取和 AI 总结管线 |
| B 站、YouTube 等受支持链接 | 已有链接导入，受站点允许列表限制；B 站结合字幕和抽样画面 |
| 本地视频 | 已有文件导入与音轨转写；可以继续补抽帧和画面内容整合 |
| 浏览器直接录音 | 后续增加录音、暂停、试听，再复用本次音频导入管线 |
| 图片、扫描 PDF | 已实现本地 OCR 与分页原文，见[文件导入说明](file-course-import.md) |
| PPTX 课件 | 已实现文字、备注、图表数据与位图 OCR，见[文件导入说明](file-course-import.md) |
| 多文件批量导入 | 已实现每批最多 50 个文件、一个文件一个课时及失败项重试；文件夹目录结构导入尚未实现 |
| 主题、学习目标生成课程 | 后续先生成可编辑课程目录，再逐课生成内容与测验 |
| 播客/RSS | 后续解析节目列表与音频源，再接音频转写管线 |

后续选定一种方式即可按上述范围继续开发；表中标记“后续”的项目尚未实现。
